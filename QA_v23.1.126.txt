Version/update path QA
1. Existing index.html already requests version.js with buildProbe=Date.now(), bypassing a stale cached version.js.
2. v23.1.126 version.js loads ui-hotfix-v23.1.126.js with the current version and a timestamp query.
3. The hotfix automatically fetches version.js with cache:'no-store' plus updateProbe timestamp.
4. It parses CAMPING_APP_VERSION from the freshly fetched file.
5. When published version differs from the running version, Options > App version changes the control to Reload latest version.
6. Reload latest version navigates to CAMPING_APP_ENTRY/index.html with a new reload timestamp query, forcing a fresh app shell request.
7. Focus/visibility checks are rate-limited to once per five minutes; the initial startup check is forced.
