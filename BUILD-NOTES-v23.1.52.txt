Modern-layer judgment note:
- General Sibley remains Modern. Official/operator proof supports electric sites, showers, water, dump station, campsite map, reservations, and modern campground infrastructure. The rules now explicitly allow practical modern-restroom inference when electric + showers/bathhouse/restroom infrastructure are supported and no source indicates vault/portable/no modern restroom.

App behavior change:
- Manual Select All / large state selection behavior remains unchanged.
- On startup, if saved/restored state settings would load a large/very large record set and the app has not been used for more than 30 minutes, the same large-selection confirmation appears before loading.
- A fresh same-session refresh stays quiet because recent activity is recorded in localStorage and beforeunload.
- If the user cancels the stale restored heavy-selection confirmation, the app falls back to the default MI selection instead of loading every saved state.
