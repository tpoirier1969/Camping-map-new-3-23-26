App behavior changes:
- Replaces separate Official Area Outlines / USFS Boundaries UI with two cleaner area overlay controls:
  - Federal Areas: federal reference/context outlines, including detailed existing federal outlines and sparse USFS administrative boundaries.
  - State / Local Areas: county/state/local public-land area outlines.
- Federal Areas still uses the sparse viewport-loaded USFS EDW boundary overlay as a fallback context layer.
- Detailed existing federal outlines are preferred over broad USFS administrative boundaries when both represent the same forest/unit.
- State selection changes reconcile area outlines by difference: keep existing matching outlines, add new needed outlines, remove only no-longer-valid outlines.
- Broad USFS boundary refresh remains debounced, viewport-loaded, zoom-guarded, cached, and off by default unless Federal Areas is turned on.
