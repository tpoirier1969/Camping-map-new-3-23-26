Boondocking & Camping Maps v23.1.86 — startup/search-helper stabilization
Date: 2026-07-08

Purpose
- Stabilize the v23.1.85 startup/search/filter path without waiting for a separate last-known-working package.
- Fix the missing search helper cluster that caused startup/render failures after the Supabase/community UI work.
- Add Tod's clarified action/question/package trigger rule to PROJECT_RULES.md.

Changes
- app.js
  - Added siteWithinTextSearch(site).
  - Added clearSearchRevealMarker().
  - Added clearSearchMode(refresh=true).
  - Added searchResultHiddenByLayer(site).
  - These are functional helper implementations, not empty no-op stubs.
  - Search filtering now returns true when no active search exists and requires every typed search term to appear in siteText(site) when search is active.
  - Search reveal marker cleanup is defensive and works whether Leaflet exposes map.removeLayer() or marker.remove().
  - Hidden-layer search result detection now respects rest-only mode and enabled map layers.

- version.js
  - Bumped visible/runtime version to v23.1.86.
  - Set data/build label to v23.1.86-startup-search-helper-stabilization.

- PROJECT_RULES.md
  - Added an action/question/package trigger rule:
    - When Tod gives enough information to safely make a revision, make the files/package in the same turn when feasible.
    - If a defined worker batch is still missing one or more returns, remind Tod instead of prematurely integrating.
    - If Tod only asks a question, answer the question and do not package unless a fix/revision/package is also requested or clearly implied by change instructions.

- index.html
  - Included unchanged per the version-shell packaging rule because the visible app version was incremented.

- QA-v23.1.86.txt
  - Added QA notes for syntax, static startup helper scan, version-source scan, and local simulated startup-path check.

No data changes
- No campsite/state data was changed.
- No Supabase SQL/schema was changed.
- No config.js change is included.

Known caveats
- This is a surgical stabilization package based on the current v23.1.85 repo/package state and the uploaded current live model.
- I did not have Tod's separate last-known-working package. If later testing shows deeper Supabase/UI regressions beyond this search-helper cluster, use the known-working package tonight as rollback comparison.
