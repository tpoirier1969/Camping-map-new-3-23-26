Reason for data-only packaging:
The live repo has v23.1.10 source files. The app JS hardcodes VERSION='v23.1.10'. A normal v23.1.11 wrapper would require copying the full current app file forward and changing that constant. Because the full app source file was not available in the local sandbox as a complete editable file, this package intentionally updates the manifest file currently loaded by index.html (data/states-manifest-v23.1.10.js) and adds the new supplement. This avoids a broken version-update loop.
