Integration standard

Known caveats
- Many South Dakota worker discoveries are real public-facing campgrounds, but still need coordinate rescue before they should become visible active map pins.
- No Google Maps/OSM bulk coordinate extraction was run in this integration package.
- This package does not resolve every worker reject row; it focuses on active adds, durable leads, rules, and UP handoffs.
