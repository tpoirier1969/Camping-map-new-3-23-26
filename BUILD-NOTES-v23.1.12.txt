Boondocking & Camping Maps — v23.1.12 data-safe changed-files build
Date: 2026-06-10

Purpose:
Add verified Wisconsin primitive / boondocking records from the post-v23.1.11 worker batch without touching config.js.

This is a data-safe build for the current v23.1.10 loader/index structure. It updates the manifest file that the current index already loads and adds supplements. It intentionally does not include config.js, index.html, app-v23.1.10.js, app-v23.1.12.js, or version.json.

Why no app/version bump:
The currently deployed app file hardcodes VERSION='v23.1.10'. Bumping version.json without safely copying the full app file forward would cause the app to keep seeing a newer remote version and nag for an update. This package therefore ships only verified data changes.
