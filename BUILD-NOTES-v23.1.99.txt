App behavior changes:
- Fixed Official Area Outlines redraw behavior during state-selection changes.
- State selection now reconciles area outlines by difference:
  - keeps already-drawn outlines that still match the new state/filter selection;
  - loads only newly needed outlines;
  - removes only outlines that no longer match;
  - no longer clears all area outlines simply because selected states changed.
- Removed the old hard pause at more than 3 selected states for area outlines. The performance guard is now based on total available outline count instead of state count.
- Batch area-outline loading now defers panel/list refreshes until the batch ends, reducing redraw churn.
- Existing USFS Boundary Overlay behavior remains off-by-default and viewport-lazy.

- Promoted Nahma Resort Campground / Upper Peninsula Golf and Lake Resort from data/leads.js to active Michigan Private Campgrounds.
